# 健身管理系统 (Zen Kinetic) 演示用例与交互脚本

本方案旨在展示 APK 的**本地存储**、**用户自主定制**以及**数据可视化回溯**能力。

---

## 🟢 用例一：新用户上手 - “开启我的健身之旅”
**目标**：演示从本地账户创建到自定义训练计划的完整流程。

1.  **起始页**：`{{DATA:SCREEN:SCREEN_25}}` (注册/创建档案)
    *   **操作**：输入昵称，点击“立即开启”。
2.  **首页**：`{{DATA:SCREEN:SCREEN_8}}` (首页 Dashboard)
    *   **状态**：数据全为 0。点击底部导航栏“计划”。
3.  **计划页**：`{{DATA:SCREEN:SCREEN_14}}` (训练计划)
    *   **操作**：点击右上角“+”号或“创建自定义计划”。
4.  **编辑器**：`{{DATA:SCREEN:SCREEN_12}}` (创建自定义计划)
    *   **操作**：输入“晨间力量”，点击“添加动作”。
5.  **动作库**：`{{DATA:SCREEN:SCREEN_18}}` (选择动作)
    *   **操作**：勾选“深蹲”、“俯卧撑”，点击“确认选择”。
6.  **保存**：返回 `{{DATA:SCREEN:SCREEN_12}}`，点击“保存计划”。
    *   **演示重点**：强调数据已实时存储在本地数据库中。

## 🟡 用例二：日常训练 - “沉浸式执行与记录”
**目标**：演示核心训练流程及实时数据反馈。

1.  **首页入口**：`{{DATA:SCREEN:SCREEN_8}}`
    *   **操作**：点击中央醒目的“开始训练”按钮。
2.  **详情查看**：`{{DATA:SCREEN:SCREEN_17}}` (训练详情)
    *   **操作**：浏览动作清单，点击底部“开始训练”。
3.  **执行记录**：`{{DATA:SCREEN:SCREEN_35}}` (运动记录)
    *   **交互**：模拟输入重量 80kg，次数 12 次，点击“完成一组”。
    *   **演示重点**：展示大字体计时器和直观的组数反馈，强调演示时的沉浸感。

---

## 🔴 用例三：数据回溯 - “看见每一个进步”
**目标**：演示本地数据持久化后的分析与历史查看功能。

1.  **指标录入**：`{{DATA:SCREEN:SCREEN_22}}` (身体指标记录)
    *   **操作**：录入今日体重 72.5kg，查看 BMI 自动计算结果。
2.  **统计分析**：`{{DATA:SCREEN:SCREEN_31}}` (进度统计)
    *   **操作**：从底部导航切换至“统计”，查看体重趋势曲线和个人纪录。
3.  **历史足迹**：`{{DATA:SCREEN:SCREEN_6}}` (训练历史回顾)
    *   **操作**：点击日历中的日期，查看当天完成的训练项。
    *   **演示重点**：证明数据能够被跨周期、跨页面持久化存储。

## 🛠️ 技术演示建议
*   **交互提示**：演示时，可以通过点击底部导航栏（`{{DATA:COMPONENTS:COMPONENTS_11}}`）快速在首页、计划、统计、个人中心之间跳转。
*   **本地属性**：向观众强调，所有数据（SQLite 数据项、SharedPreferences 配置）在断网状态下依然可以完美运行。
