# 健身管理系统 (Zen Kinetic) 开发指导与 Prompt 建议

为了确保其他 AI 能准确理解并实现当前的设计，建议在开始对话时提供以下上下文和详细要求。

---

## 1. 技术栈与开发模式 (Android Native)
*   **开发语言**：Java 或 Kotlin (推荐 Kotlin)。
*   **核心组件**：以 **Activity** 为核心的原生开发方式。
*   **本地存储**：
    *   使用 **SQLite (Room Persistence Library)** 存储训练计划、动作库、历史记录和身体指标。
    *   使用 **SharedPreferences** 存储用户基础信息（如昵称、目标）。
*   **UI 实现**：使用 XML 布局结合 Material Design 3 组件库。

---

## 2. 核心逻辑链定义 (Data Model)
在向 AI 提问时，请先让它定义好数据模型，这是“本地存储”逻辑成功的关键：
*   **User**: 存储本地档案信息。
*   **Exercise**: 动作库（预设动作 + 用户自定义）。
*   **Plan**: 训练计划（包含多个动作映射）。
*   **WorkoutLog**: 每次训练的完成数据（关联计划 ID、完成组数、重量、时间）。
*   **BodyMetric**: 身体指标历史记录。

---

## 3. 给开发 AI 的 Prompt 建议 (可以直接复制)

### A. 初始化项目与架构
> "我正在开发一个名为 'Zen Kinetic' 的原生 Android 健身管理 App。要求使用 Kotlin 和传统的 Activity 模式。应用完全定位为 **纯本地存储**，不涉及后端 API。请帮我设计 Room 数据库架构，包含：用户档案表、动作库表、自定义训练计划表、以及训练历史记录表。请确保表结构能支持多对多的动作与计划关联。"

### B. 实现 UI 还原 (推荐逐页进行)
> "请参考我提供的 HTML/CSS 设计稿（点击我的设计稿中的 'View Code' 获取代码提供给 AI），帮我将 [页面名称，如：首页 Dashboard] 转换为 Android XML 布局代码。要求：
> 1. 使用 `Plus Jakarta Sans` 字体（或系统默认 Sans-Serif）。
> 2. 颜色代码使用：主色 #FF5247（禅意红），背景 #F8F9FA。
> 3. 组件圆角统一为 `24dp` 或更大。
> 4. 实现对应的 Activity 类，并从 Room 数据库中读取本地数据进行展示。"

### C. 实现核心交互逻辑
> "请帮我实现 [创建自定义计划] 流程的逻辑。需要包含：
> 1. 一个 Activity 用于输入计划名称并展示已选动作列表。
> 2. 点击 '添加动作' 跳转至动作库 Activity，支持搜索和多选。
> 3. 点击 '保存' 后将数据持久化到 SQLite 数据库中。
> 4. 注意：所有状态管理必须在本地完成，无需网络请求。"

---

## 4. 关键避坑说明 (给您的建议)
1.  **静态数据先行**：在演示时，建议先写一个 `DataGenerator` 类，在应用启动时向 SQLite 插入一些预设数据，这样演示时页面就不会是空的。
2.  **图表库选择**：建议告诉 AI “使用 `MPAndroidChart` 库来绘制体重趋势图和统计图表”。
3.  **UI 细节**：强调“禅意律动”风格的精髓在于 **留白 (Spacing)** 和 **低饱和度阴影**，让 AI 在写 XML 时注意 `margin` 和 `elevation` 的使用。
